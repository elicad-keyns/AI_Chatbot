# День 22 — сравнение ответов с RAG и без RAG

Корпус: `summaries/2026_06_29_RAG_Эмбеддинги,_векторный_поиск_и_чанкинг.md`.

## Как провести сравнение

1. В настройках выберите папку `summaries` и постройте оба индекса.
2. Для каждого вопроса из `day22_control_questions.json` сначала включите `RAG: OFF`.
3. Сохраните ответ модели и отметьте наличие ожидаемых фактов. Источники в этом режиме отсутствуют.
4. Включите `RAG: ON`, выберите `structural`, `Top-K = 5`, threshold `0.25` и повторите вопрос.
5. Проверьте inline-цитаты `[S1]` и плашки `source / section / chunk_id` под ответом.

## Рубрика одного ответа

| Критерий | Баллы |
|---|---:|
| Все ожидаемые факты присутствуют | 0–2 |
| Использован ожидаемый источник/раздел | 0–1 |
| Нет неподтверждённых документом утверждений | 0–1 |
| Цитаты действительно поддерживают утверждения | 0–1 |
| **Итого** | **0–5** |
